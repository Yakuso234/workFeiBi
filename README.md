# workFeiBi

一个透明、置顶、可拖动的学习监督桌宠：菲比啾比 + 弗糯糯参考重绘试用版。Windows / Electron，离线运行，无账号、无遥测。

## v1.1 功能

- 黄黑 / 青红赛博朋克终端：专注舱、任务档案、参数配置三个页面。
- 学习 / 休息倒计时，默认 60 秒未确认后生气，支持暂停、跳过、重置。
- 角色切换：菲比三种原始外观；弗糯糯 1280×1280 正面、休息、背面补绘素材。
- 摸头、喂点心、伸懒腰、打盹各自切换不同姿势；待机每 3～7 秒随机摇头、眨眼、挥手、抬脚、伸展或转身。两名角色均有独立困倦与后视姿势，可手动点击“转身看看”。提醒优先于互动，连续点击有冷却。
- 生气时会切到举拳敲屏姿势：桌宠周围出现约 2.6 秒的透明裂纹冲击特效。它鼠标穿透、自动消失，不会修改壁纸或桌面文件。
- 今日完成轮数、完整轮次分钟数、最近七天记录、每日目标与任务清单。
- 退出保存计时，下次打开暂停待续；运行期间每 15 秒保存检查点。强制结束可能丢失最近 15 秒；未确认提醒会保留。正常运行的计时包含系统休眠时间，不把计时统计冒称实际学习监测。
- 分角色导入 MP3 / WAV / OGG（不超过 5 MB），保存在本机，不上传到仓库。

## 启动

本机已打包版本：双击 `启动workFeiBi.vbs`，或直接打开 `release/workFeiBi/workFeiBi.exe`。不需要联网，也不需要另装 Node.js。请保留整个 `release/workFeiBi` 文件夹，不能单独移动 EXE。Git 仓库只保存源码，不包含这个大体积构建目录。

`启动菲比学习小助手.bat` 也可启动；若独立程序不存在，会使用 Node.js 开发模式。

也可以在终端运行：

```powershell
npm install
node node_modules/electron/install.js
npm start
```

## 操作

- 拖动菲比：移动桌宠。
- 单击菲比：互动；提醒出现时用于确认。
- 双击菲比：打开计时设置。
- 右键菲比：开始/暂停、跳过、重置、隐藏或退出。
- 学习或休息倒计时结束后会出现提示；普通菲比提醒使用约 1.30 倍速的更高、更稚气“啾比”音色，默认 60 秒未确认后则用本机中文语音念“菲吧揪比”。当前本机独立版可随机播放经作者许可的糯糯短音效；该音频不进 Git。缺少本地许可文件时，弗糯糯回退为系统中文语音或合成提示音。原始音频文件不被改写，仅在播放时升调加速。

参数配置页面可修改时长、大小、角色、外观、声音和待机动作。角色与参数修改后需要点击“保存设置”；语音导入针对当前已保存的角色。

系统托盘可恢复隐藏的桌宠；Ctrl+Shift+F 切换显隐。设置与拖动位置自动保存。修改时长在下一轮生效，保存后重置可立即应用。关闭设置窗口不会退出桌宠；退出请用右键菜单。

菲比使用原始 500×500 透明 PNG，保留原眼型；后视和互动姿势为额外生成的透明试用图。弗糯糯为参考 Akaoni 二创的 AI 重绘试用版，背面和互动姿势均是补绘而非官方设定。动作包含程序位移、姿势图片切换和屏幕特效，不是完整逐帧动画。弗糯糯默认使用合成提示音；网上“糯糯”短叫声尚未核验为内置音效，可用本地导入替换。详见 `docs/ART-NOTES.md`。

运行 `npm test` 检查计时状态；`npm run smoke` 运行窗口/音频解码/提醒与确认验证，截图输出至 qa；`npm run build` 生成 release 下的独立 EXE 目录。独立版需要保留整个文件夹，无需 Node.js。

## 本地数据与隐私

配置、任务、统计与自定义语音在 Electron 用户数据目录下（通常 `%APPDATA%/workFeiBi`）。旧版本开发模式可能沿用 `%APPDATA%/workfeibi`。配置采用临时文件替换与上一版备份；遇到损坏尝试恢复。应用本身不联网拉取图片或上传这些数据。测试使用独立 `.qa-profile`，不覆盖日常配置。
