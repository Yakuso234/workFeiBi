# workFeiBi

一个透明、置顶、可拖动的学习监督桌宠：菲比啾比、弗糯糯参考重绘试用版、原创发条鸮，以及 Q 版初音未来。Windows / Electron，离线运行，无账号、无遥测。

## v1.4.1 学习节奏与鼓励

- 可选周期性长休息：默认关闭，开启后默认每完成 4 轮专注休息 15 分钟，可修改间隔和时长。只有完成并确认的学习才参与安排，跳过学习不会获得长休。
- 修改参数不改变正在进行的轮次；当前长休保持原时长，下一轮或显式重置才应用新设置。退出后仍暂停待续，旧配置正常沿用短休。
- 「给我加油」轮换六句鼓励，沿用互动冷却；勾选完成任务时桌宠会送出小爱心。庆祝不额外增加专注或陪伴数值，到期提醒始终优先。
- 街机可按 Esc 随时退出；刚点击开始、请求尚未返回时也可取消，不会偷偷在后台计分。

## v1.4 陪伴扩展

- 新增初音未来：原作者涂山苏苏的 40 张 1024×1024 透明 WebP，待机、眨眼、挠头、开心、困倦、生气、拖起和起身均使用实际帧序列，每帧 200ms。生气后保留气鼓鼓表情，确认提醒才恢复。没有原始背面轨，转身按钮在初音下隐藏；「挥手/抬脚」对应挠头/开心轨，而不是虚构新动作。
- 「角色收藏」展示四个伙伴及各自动画说明，点击「出场」立即切换。仅保存角色选择，不覆盖尚未保存的时长、音量等表单草稿，也不重置计时。
- 发条鸮新增经典鎏金、霓虹电路、月光星尘三套配色，以及星星发夹、陪伴耳机。在参数配置选择并保存；前后绘制和透明命中都跟随头饰更新。
- 「休息街机」接星星：仅休息阶段或学习暂停时主动开启，每局最多 45 秒/60 颗。桌宠每接到五颗会加油。游戏纪录、完成局数和星星总数保存在本机，不增加专注轮数或陪伴数值。
- 计时提醒优先：到期、恢复学习、切角色、离开街机、关闭/最小化终端会结束当前局；取消不记成绩。可用 Tab 选中星星，然后空格/Enter；也可按 Esc 或点击结束。游戏会在下一次打开时保持未运行，不补计离线成绩。
- 公开构建只包含固定动画白名单和来源文件；未下载的上游轨道、完整上游玩法与本地许可音频不进入公开构建。初音默认使用电子提示音，没有复制歌曲或声库，允许自行导入有权使用的本机音效。

初音素材固定于 [dsh-pet](https://github.com/zhu1090093659/dsh-pet/tree/36f605619bdf5445e84493b7faaf2bbb51077b14/assets/miku)，作者图片许可与角色条件见 `ASSET-SOURCES.md`。菲比/糯糯真正连续帧仍是后续项，本轮增加新伙伴不会改变这个状态。

## v1.3 第一阶段

- 新增原创「发条鸮」：代码原生 SVG 分层形象，翅膀、脚、眼皮、头部独立动作；支持挥翅、踢脚、伸展、眨眼、困倦、生气和真正不同的后背结构。不同大小依然清晰，默认使用电子提示音，也可本机导入声音。
- 当前四个角色统一在参数配置中选择，保存后切换，也可从角色收藏直接出场。菲比和糯糯保留原有素材与音效；既有角色完整逐帧动画仍待制作。
- 「任务档案」新增 CSV / JSON 本地导出：CSV 是日期、完整专注轮数和精确秒数；JSON 另含当前任务文字、完成状态与共享陪伴成长。最多导出本地仍保留的最近 90 个有记录日期和 30 个当前任务，不含音频、窗口位置及配置路径。保存前由你选择位置，取消不产生文件。
- JSON 是数据档案，不是全量配置备份；当前不提供一键导入恢复。任务文字可能包含私人信息，请留意导出文件保存位置。

发条鸮采用关节层动画；菲比和糯糯仍采用局部闭眼、姿势切换与整图动效。本版本不是后续路线图中“所有角色全套连续动画”的完成版。

## v1.2 功能

- 黄黑 / 青红赛博朋克终端：专注舱、任务档案、参数配置、动作实验室，现另有角色收藏与休息街机。
- 学习 / 休息倒计时，默认 60 秒未确认后生气，支持暂停、跳过、重置。
- 角色切换：菲比三种原始外观；弗糯糯 1254×1254 正面、休息、背面补绘素材。
- 去重随机待机：安静 10～18 秒、自然 5～9 秒、活泼 3～5.5 秒的调度间隔；提醒和主动互动优先。自动待机关闭后会停止，学习运行中默认只保留轻眨眼，减少动态可关闭大幅运动。
- 两名角色都有局部闭眼效果；摸头有爱心，喂食有点心，打盹持续 8 秒，转身使用背面图。挥手、踢脚、伸展仍共享举手姿势，通过不同程序动效区分，并非独立逐帧肢体动画。菲比摘帽/节日外观保持原图，不混入戴帽补绘姿势。
- 动作实验室可以直接试 8 种动作，不改变陪伴进度或计时阶段；有到时提醒时必须先确认。
- 生气时会切到举拳姿势，附近出现约 2.6 秒的分叉裂纹、冲击圈和碎片。特效窗口鼠标穿透、自动消失，支持关闭；隐藏桌宠、确认提醒或启用减少动态也会收起，不修改桌面文件。
- 持久化陪伴成长：默契、心情、精神、累计互动、共同完成轮次和纪念章。当前四个角色共享一份陪伴记录；离线不扣分，不要求打卡。预览和小游戏不奖励，连点有 2.5 秒冷却。
- 今日完成轮数、完整轮次分钟数、最近七天记录、每日目标与任务清单。
- 退出保存计时，下次打开暂停待续；运行期间每 15 秒保存检查点。强制结束可能丢失最近 15 秒；未确认提醒会保留。正常运行的计时包含系统休眠时间，不把计时统计冒称实际学习监测。
- 分角色导入 MP3 / WAV / OGG（不超过 5 MB），保存在本机，不上传到仓库。

## 启动

本机已打包版本：双击 `启动workFeiBi.vbs`，或直接打开 `release/workFeiBi/workFeiBi.exe`。不需要联网，也不需要另装 Node.js。请保留整个 `release/workFeiBi` 文件夹，不能单独移动 EXE。Git 仓库只保存源码，不包含这个大体积构建目录。

`启动菲比学习小助手.bat` 也可启动；若独立程序不存在，会使用 Node.js 开发模式。

也可以在终端运行：

```powershell
npm install
node node_modules/electron/install.js
npm start
```

## 操作

- 拖动菲比：移动桌宠。
- 单击菲比：互动；提醒出现时用于确认。
- 双击菲比：打开计时设置。
- 右键菲比：开始/暂停、跳过、重置、隐藏或退出。
- 学习或休息倒计时结束后会出现提示；普通菲比提醒使用约 1.30 倍速的更高、更稚气“啾比”音色，默认 60 秒未确认后则用本机中文语音念“菲吧揪比”。当前本机独立版可随机播放经作者许可的糯糯短音效；该音频不进 Git。缺少本地许可文件时，弗糯糯回退为系统中文语音或合成提示音。原始音频文件不被改写，仅在播放时升调加速。

参数配置页面可修改时长、大小、角色、外观、声音和待机动作。25/5、50/10、90/15 预设仅填入表单，保存后才生效。角色与参数修改后需要点击“保存设置”；语音导入针对当前已保存的角色。互动声音默认关闭；专注安静模式在学习计时运行时也会静音，结束后的正式提醒仍遵循总声音开关。

系统托盘可恢复隐藏的桌宠；Ctrl+Shift+F 切换显隐。设置与拖动位置自动保存。修改时长在下一轮生效，保存后重置可立即应用。关闭设置窗口不会退出桌宠；退出请用右键菜单。

菲比使用原始 500×500 透明 PNG，保留睁眼眼型；后视和互动姿势为额外生成的透明试用图，眨眼是局部画布覆盖。弗糯糯为参考 Akaoni 二创的 AI 重绘试用版，背面和互动姿势均是补绘而非官方设定。动作包含程序位移、姿势图片切换和屏幕特效，不是完整逐帧动画。缺少本地许可音效的源码版本会回退为系统中文语音/合成提示音。声音播放失败也会回退；可爱程度和实际内容仍需本机试听。详见 `docs/ART-NOTES.md`。

运行 `npm test` 检查状态和行为规则；`npm run check` 检查语法；`npm run smoke` 运行隔离窗口验证，截图输出至 qa。测试控制台中的“未知动作”“请先确认到期提醒”是故意测试拒绝分支；最终应看到 `SMOKE PASS`。

`npm run build` 生成 `release/workFeiBi` 下独立 EXE，默认不带 `local-media`。本机若有许可音频，可用 `npm run build:local`，仅复制三个白名单短片段，这种构建仅供本机使用，不公开分享。构建前需备份/移走已有输出目录，脚本不会覆盖旧版本。独立版需要保留整个文件夹，无需 Node.js。

## 本地数据与隐私

配置、任务、统计与自定义语音在 Electron 用户数据目录下（通常 `%APPDATA%/workFeiBi`）。旧版本开发模式可能沿用 `%APPDATA%/workfeibi`。配置采用临时文件替换与上一版备份；遇到损坏尝试恢复。应用本身不联网拉取图片或上传这些数据。测试使用独立 `.qa-profile`，不覆盖日常配置。
