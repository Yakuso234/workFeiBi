## 弗糯糯试用素材

原型参考：Akaoni / 赤鬼风格的弗洛洛二创，灰青色大头发、粉蓝色半睁呆眼、红白衣服。

参考页面：https://safebooru.org/index.php?id=6354064&page=post&s=view （页面标注 akaoni (zumt3548)，1156×1230）。页面标注不代表已取得独立商用授权。

`assets/images/nuonuo_front.png`、`nuonuo_back.png`、`nuonuo_wave.png`、`nuonuo_drowsy.png`、`nuonuo_angry.png` 是内置 imagegen 按参考重绘的透明底试用图片。原生成画布为 1280×1280，当前处理后的 PNG 实测为 1254×1254；不是原作者未修改原图，不是游戏官方设定或原始动画帧。

生成提示要点：

- 正面：保留宽圆脸、灰青长发、平直刘海、粉蓝半睁呆眼、小横嘴、红白服装；补全短裙、短腿及鞋；单角色完整轮廓、真正透明背景、无文字。
- 困倦：与正面保持比例，抱膝、近闭眼与小幅歪头；不添加符号与背景。
- 互动/生气：挥手抬脚，以及冷脸举拳敲屏；保留半睁、呆滞的粉蓝眼型。
- 背面：长发遮住肩背；禁止正面领口、胸花、前衣襟；只露简单红色后裙摆、后鞋跟；从背面看左袖为白色配红色缠带，右袖红色。背面为合理补绘，不宣称原作者设定。

首版背面曾错误沿用胸前装饰，现已修正并替换。弃用版本不进入项目仓库。运行时使用上述五张最终透明姿势图，原始候选参考不上传。

v1.2 未新增角色位图。眨眼通过前视图上的局部画布覆盖实现；爱心、点心和碎屏也由代码绘制。挥手、踢脚和伸展共享举手姿势图，分别配不同变换，不是逐帧骨骼动画。菲比摘帽与节日外观保留原图，不使用戴帽生成姿势，避免自动待机换帽；真多帧资源另列入路线图。

## 音频边界

菲比内置音效的来源见 ASSET-SOURCES.md。2026-09-22 公开页虽存在“未经作者授权，禁止转载”提示，但用户确认已直接向作者取得仅限本机下载使用的许可；因此仅从该本地许可音轨裁出三个短片段并放在 Git 忽略的 `local-media/nuonuo/`。它们不进入源码仓库、不上传、不作为公开再分发资源。若本地片段缺失，默认使用系统中文语音/合成提示音；自定义导入支持 MP3/WAV/OGG（5 MB 内），仅保存本机用户配置目录，不进入 Git 仓库。
